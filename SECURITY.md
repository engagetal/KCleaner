# Security

Report vulnerabilities privately to **hello@engagetal.com**, with the subject “KCleaner security report”. Include affected version, impact, reproduction steps, and any proposed fix. Avoid public issues for exploitable security details until the issue has been assessed. Do not send passwords or unrelated personal data.

KCleaner intercepts keyboard input through macOS Accessibility APIs. Changes to event handling, emergency unlock, resource loading, and the uninstaller deserve particular care. The app is a cleaning aid, not a security boundary or a guarantee that all hardware/system shortcuts are blocked.

Use the latest published version. No fixed response-time or maintenance guarantee is offered. The source-pattern scan in `build.sh` is not a substitute for a security review.
