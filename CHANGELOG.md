# Changelog

## 1.0.0 — 2026-10-19

First public GitHub release of KCleaner by Engagetal Solutions.

- Native macOS keyboard cleaning mode with a visual key map.
- Optional timed pointer blocking, hold-to-finish control, and emergency exit.
- Supplied KCleaner 1.0 DMG for download.
- Complete Swift source, MIT License, build and contribution documentation.
- Script for exact integer GitHub-reported DMG download counts.

The supplied binary is unchanged. Publication changes to source are licensing notices; documentation and the counter script are new.
